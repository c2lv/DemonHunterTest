# Slay the Spire 2 MOD: 악마사냥꾼 일리단 스톰레이지
[`Slay the Spire 2`](https://store.steampowered.com/app/2868840/Slay_the_Spire_2/)(이하 StS2)에 `월드 오브 워크래프트`의 `악마사냥꾼` `일리단 스톰레이지`와, `하스스톤`의 키워드를 추가한 팬 MOD입니다.

## 캐릭터 컨셉
하이 리스크, 하이 리턴  
턴이 지날수록 적과 함께 강해지는 캐릭터로 전략적인 플레이를 즐겨보세요.

## 새로운 키워드
- 추방자  
  내 **손**의 맨 왼쪽 또는 오른쪽에서만 사용할 수 있습니다.
- 하이랜더  
  **뽑을 카드 더미**에 중복된 카드가 없으면 사용할 수 있습니다.
- 도발  
  이 카드가 **손**에 있다면, 다른 카드보다 먼저 사용해야 합니다.

## 추천 플레이 전략
- 일리다리  
- 추방자  
- 하이랜더  

## 모드 적용 방법
1. StS2 게임이 있는 로컬 폴더(윈도우 기본 경로: `C:\Program Files (x86)\Steam\steamapps\common\Slay the Spire 2`)를 열고, mods/ 폴더가 없다면 생성합니다.
2. **(필수)** [BaseLib](https://github.com/Alchyr/BaseLib-StS2/releases)를 다운로드하고 mods/ 폴더에 압축 해제하세요. (일반적으로 MOD 파일에는 .dll, .json, .pck 파일이 들어있습니다.)
3. [DemonHunterMOD](https://github.com/c2lv/DemonHunterTest/releases)를 다운로드하고 mods/ 폴더에 압축 해제하세요.
4. **(선택)** 기본적으로 MOD가 적용된 세이브 파일은 그렇지 않은 파일과 별도로 저장됩니다. 이를 통합해주는 [UnifiedSavePath](https://www.nexusmods.com/slaythespire2/mods/6)도 mods/ 폴더에 압축 해제하여 사용하기를 권장합니다.
